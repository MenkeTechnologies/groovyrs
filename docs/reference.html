>_BUILTIN REFERENCE

Every reserved keyword, literal, and script command the current groovyrs build recognizes, grouped by keyword then literal then command. This page is generated from the language-server corpus (src/lsp.rs) by the gen-docs binary, so it stays in sync with what the runtime and editor tooling actually know about. Keywords/literals mirror lexer.rs; each command mirrors a real print builtin in src/host.rs.

Keyword

# def

declare a dynamically-typed local variable (or a script binding)

def x = 5
println(x)   // => 5

# if

conditional branch; runs the block when the condition is truthy

if (1 < 2) println("yes")   // => yes

# else

fallback branch of an `if`

if (false) println("a") else println("b")   // => b

# while

loop while the condition is truthy

def i = 0
while (i < 3) i++
println(i)   // => 3

# assert

raise an `AssertionError` when the condition is falsy, rendering each sub-expression's value

assert 1 + 1 == 2   // passes silently

# do

`do { … } while (cond)`; the body runs before the first test

def i = 0
do { i++ } while (i < 3)
println(i)   // => 3

# switch

multi-way branch on Groovy's `isCase` (constant, range, list, type, `~/…/`, closure)

switch (5) { case 4..6: println("in"); break; default: println("out") }   // => in

# case

one `switch` label; sections fall through until a `break`

switch (1) { case 1: println("one"); break }   // => one

# default

the `switch` section entered when no `case` label matched; also marks an interface method with a body

switch (9) { case 1: break; default: println("d") }   // => d

# for

C-style `for (init; cond; update)`, the `for (x in a..b)` range loop, or `for (x in collection)`

for (i in 0..2) print(i)   // => 012

# in

the `for (x in …)` iteration separator; walks a range, a list, a map's entries, or a String's characters

for (n in [1, 2, 3]) print(n)   // => 123

# return

end the script; a returned expression is evaluated for its effects

return   // ends the script here

# break

exit the nearest enclosing loop or `switch`; `break label` exits the named one

for (i in 0..9) { if (i == 3) break; print(i) }   // => 012

# continue

skip to the next iteration of the nearest loop; `continue label` targets the named one

for (i in 0..3) { if (i == 1) continue; print(i) }   // => 023

# new

construct a class instance (`new Type(args)`)

class P { def x; P(v) { x = v } }
println(new P(7).x)   // => 7

# try

run a block with `catch` handlers and/or a `finally` cleanup

try { throw new Exception("x") } catch (Exception e) { println(e.message) }   // => x

# catch

handle a thrown exception of the named type (`catch (A | B e)` for several)

try { 1 / 0 } catch (ArithmeticException e) { println(e.message) }   // => Division by zero

# finally

cleanup block; runs on every exit path out of the `try`, including a `return`

try { println("body") } finally { println("cleanup") }   // => body\ncleanup

# throw

raise a throwable, unwinding to the innermost matching `catch`

try { throw new IllegalStateException("bad") } catch (Exception e) { println(e) }

Literal

# true

the boolean true value

println(true)   // => true

# false

the boolean false value

println(1 > 2)   // => false

# null

the null reference; an unassigned `def` reads as null

def x
println(x)   // => null

Command

# println

print a Groovy-formatted value and a trailing newline

println("hi")   // prints hi\n

# print

print a Groovy-formatted value with no trailing newline

print("a"); print("b")   // prints ab
